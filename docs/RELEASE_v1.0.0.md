# N0JCG NOAA Weather Radio v1.0.0

First packaged product release of N0JCG NOAA Weather Radio.

## Included

- Receive-only NOAA Weather Radio dashboard using RTL-SDR serial `00000162`.
- FFT survey across all seven NOAA channels with strongest-candidate selection.
- Direct channel tuning, browser audio, and configurable SAME county/event filters.
- Product-scoped registration using product ID `n0jcg-noaa-weather-radio` and license prefix `N0JCG-NWR-`.
- Standard N0JCG application footer with runtime release version and external links.
- Scanner-standard operator guide, current live screenshots, installer, and versioned release package.

## Validation boundary

Software tests, Python/JavaScript checks, release packaging, live Pi deployment, `/VERSION` validation, and browser footer markup validation completed. Live RF coverage, intelligible audio, antenna performance, and end-to-end SAME acceptance remain target-hardware validation activities.
