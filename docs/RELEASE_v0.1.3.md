# N0JCG NOAA Weather Radio v0.1.3

Preview release focused on product registration, operator documentation, and customer-facing publication.

## Included

- Product-scoped registration with product ID `n0jcg-noaa-weather-radio`.
- License prefix validation for `N0JCG-NWR-` licenses.
- Hamburger-menu activation with registered email and installation details.
- Five-minute trial card and timer while unregistered; trial card removed after successful activation.
- Compact Start/Stop dashboard, FFT-ranked NOAA channel survey, direct channel tuning, browser PCM audio, and SAME filters.
- Updated operator guide in Markdown, PDF, and DOCX formats with dashboard and registration-menu screenshots.
- Raspberry Pi deployment package for RTL-SDR serial `00000162`.

## Validation boundary

Software tests, UI checks, package construction, and Pi service/API checks are complete. Live RF coverage, intelligible audio, and end-to-end SAME alert acceptance remain target-hardware validation activities.
