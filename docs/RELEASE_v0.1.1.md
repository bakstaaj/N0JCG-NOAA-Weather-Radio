# N0JCG NOAA Weather Radio v0.1.1

## Release summary

This release packages the compact operator dashboard and the current browser
audio workflow for the standalone N0JCG NOAA Weather Radio product.

## Included

- Serial-locked RTL-SDR ownership for `00000162`.
- Seven-channel NOAA FFT survey with strongest-candidate selection.
- Single Start/Stop control and direct tuning from candidate cards.
- Scheduled short WAV browser-audio segments for the selected NFM channel.
- Configurable SAME county/event filters, ALL event selection, Save / Update,
  persisted settings, and alert history.
- Five-minute trial registration with restart behavior.
- Independent Raspberry Pi service, installer, package tooling, and user guide.

## Validation

- Python unit tests: six passing.
- JavaScript syntax check: `node --check web/app.js`.
- Installer check-only validation.
- Release archive SHA-256 generated by `tools/package_release.py`.
- Live Pi service and audio endpoint previously verified on port 8086; live RF,
  antenna coverage, and end-to-end SAME acceptance remain target-hardware gates.

## Deployment identity

- Service: `n0jcg-noaa-weather-radio.service`
- Application root: `/opt/n0jcg-noaa-weather-radio`
- Port: `8086`
- Receiver: RTL-SDR EEPROM serial `00000162`

## Boundaries

This is receive-only software. A READY state or browser audio connection proves
software-path state, not intelligible NOAA reception or emergency-warning
delivery. Keep an official weather alert source available.
